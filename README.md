# Manual Crossbow Reloading - SKSE
Gameplay addon that prevents crossbows from reloading automatically after firing and allows doing so manually instead. SKSE plugin.

### Requirements
* [XMake](https://xmake.io) [3.0.0+]
* C++23 Compiler (MSVC, Clang-CL)

### Build
To build the project, run the following command:
```bat
xmake build
```
